# Progression

## 1. 成長の4本柱

プレイヤーの成長を1本のLevelに集約しない。

主要成長軸:

1. Angler Level
2. Reputation
3. Assets
4. Knowledge

それぞれ役割を分離する。

## 2. Angler Level

### 2.1 基本

- Lv1〜100
- 釣り人としての総合経験
- 主に魚の捕獲、挑戦、発見からXPを得る
- 地域への入場キーには原則しない

レベル帯イメージ:

- Lv1〜10: 初心者
- Lv11〜30: 一般アングラー
- Lv31〜50: 熟練者
- Lv51〜70: 上級者
- Lv71〜90: エキスパート
- Lv91〜100: マスター

Lv100でも魚が自動的に釣れるわけではない。

## 3. Levelが表すもの

レベル上昇は「人間としての釣り技術向上」を表現する。

能力候補:

- Casting
- Line Control
- Hooking
- Fighting
- Landing
- Detection
- Rigging

例:

同じロッド・リールでも、Lv1では性能を十分引き出せない。
経験を積むほどキャスト精度、テンション管理、アワセ、ドラグ操作等が安定する。

## 4. Skill Point

原則としてLevel UpごとにSkill Pointを得る。

プレイヤーは自分の得意分野を伸ばせる。

例:

### 遠投型

- Casting 高
- Line Control 中
- Fighting 中

### 大物型

- Fighting 高
- Landing 高
- Line Control 高

### 繊細型

- Detection 高
- Rigging 高
- Hooking 高

Skill Pointの振り直し仕様は後で決定する。

## 5. Perk

一定LevelごとにPerkを解禁する。

Perkは魔法ではなく、経験・技術として説明できるものに限定する。

例:

- Accurate Cast: キャスト誤差軽減
- Line Sense: 小さなアタリを認識しやすくなる
- Drag Control: ドラグ調整の許容範囲拡大
- Efficient Rigging: 仕掛け交換時間短縮
- Big Fish Control: 大型魚の急な走りへの対応補助
- Quick Landing: 取り込み操作の安定性向上

## 6. XP

XP = Base XP × Challenge Modifiers + Bonuses

主要要素:

### Base XP

魚種・個体・釣法の基本難度。

### Size Bonus

同種のサイズ分布に対する上位率。

例:

- 標準域: x1.0
- 上位10%: x1.5
- 上位1%: x3.0
- 上位0.1%: x8.0

実倍率はバランス調整で決定する。

### First Catch

初魚種捕獲。

大きなXPボーナス。

### Elite Bonus

特殊個体捕獲。

### Personal Record

自己記録更新。

### New Location

初めてその地域で対象魚を釣る。

### New Method

初めて特定釣法で捕獲。

## 7. 反復XP減衰

同じ簡単な魚を大量に釣るだけでLv100にならないようにする。

同一魚種・同一条件での反復にはXP減衰を導入する。

ただし以下は減衰対象外または緩和する。

- 自己記録更新
- Trophy
- Elite
- 新しいSpot
- 新しい釣法
- 特殊な条件での捕獲

ゲームがプレイヤーに「新しい挑戦」を促す設計にする。

## 8. 釣法熟練度

Angler Levelとは別に、カテゴリ別熟練度を持てる構造にする。

初期候補:

- Lure
- Bait
- Freshwater
- Saltwater
- Shore
- Boat

将来細分化可能:

- Bass
- Trout
- Ajing
- Eging
- Surf
- Rock Fishing
- Fly
- Jigging
- Trolling
- Big Game

Lv70の熟練者でも初めての釣法は完全習得状態ではない。

## 9. Reputation

Levelとは分離する。

### Level
本人がどれほど経験・技術を持つか。

### Reputation
周囲からどれほど知られ、信用されているか。

Reputation獲得要因:

- 記録級魚
- 大会成績
- 難しい魚の捕獲
- 継続的な釣果
- 地域活動
- 釣具店・船宿との関係
- メーカーイベント
- 情報発信

解禁候補:

- 限定情報
- 特殊釣行
- ガイド紹介
- 大会
- メーカー案件
- 試作品
- 招待ポイント

## 10. Assets

資産による進行。

主要カテゴリ:

- Cash
- Rods / Reels / Gear
- Bicycle
- Motorcycle
- Car
- SUV / 4WD
- Kayak
- Trailer Boat
- Boat
- Fish Finder
- Storage
- Home upgrades

Assetsは「数値的に強くなる」だけでなくアクセス可能な場所・時間・荷物量を変える。

## 11. Knowledge

Knowledgeは以下の単位で保持できる。

- Fish Knowledge
- Spot Knowledge
- Region Knowledge
- Method Knowledge

Knowledgeは成功率を直接上げるだけでなく、プレイヤーに判断材料を表示する。

例:

Knowledge 0:
- 魚種不明
- 水深不明
- ベイト不明

Knowledge 高:
- 朝夕の時合い
- 季節パターン
- 地形
- 回遊傾向
- 有効ルアー
- 雨後の変化

## 12. 場所の解禁ルール

「Lv30だから入れる」は原則禁止。

アクセスは条件の組み合わせで決める。

例: 山間部Spot

- Spotを知っている
- 移動手段がある
- 季節的にアクセス可能
- 必要なら遊漁券を持っている

例: オフショア

- 乗合船予約または自艇
- 費用
- 対応タックル
- 出船可能な天候
- 必要な情報

低Levelでも挑戦できる場合は残す。
ただし経験不足により難易度は高くなる。

## 13. 推奨Level

魚や釣りには Recommended Angler Level を設定可能。

これはロックではない。

例:

スズキ大型個体
Recommended Lv 20

Lv5でも挑戦できる。

低Levelで高難度魚を獲った場合は大きなAchievementやXPボーナスを与えられる。

## 14. 成長の理想形

プレイヤーが次のように感じることを目指す。

- 上手くなった
- 知識が増えた
- 行ける場所が増えた
- 狙える魚が増えた
- 良い道具を使いこなせるようになった
- 釣り仲間や店との関係が増えた
- 以前獲れなかった魚を獲れるようになった

単純な「攻撃力の数字が増えた」にはしない。
